/api/v2/ams/get\_open\_campaign\_added\_product

Recupere todos os produtos atualmente em campanha, incluindo o status da campanha, a taxa de comissão e o período promocional.

| tamanho\_da\_página | int32 | Verdadeiro | 20 | Cada conjunto de resultados é retornado como uma página de entradas. Use os filtros "page\_size" para controlar o número máximo de entradas a serem recuperadas por página (ou seja, por chamada). Esse valor inteiro é usado para especificar o número máximo de entradas a serem retornadas em uma única "página" de dados. O limite de page\_size está entre 1 e 100. |
| cursor | corda | Falso | 1234.5678 | Especifica a entrada inicial dos dados a serem retornados na chamada atual. O padrão é "" ou nenhum valor é passado. Se os dados tiverem mais de uma página, o cursor pode apontar para alguma entrada que servirá de ponto de partida para a próxima chamada. |
| ordenar por | corda | Falso | taxa\_de\_comissão | Use este campo para especificar qual campo usar para classificar a lista de itens retornada. Valores disponíveis:  taxa\_de\_comissão: Ordenar por taxa\_de\_comissão em ordem crescente  \-taxa\_de\_comissão: Ordenar por taxa\_de\_comissão em ordem decrescente |
| tipo\_de\_busca | corda | Falso | NOME\_DO\_ITEM | Tipo de pesquisa: ITEM\_NAME ou ITEM\_ID |
| conteúdo\_de\_busca | corda | Falso | teste | A busca deve ser feita pelo nome do item ou pelo ID do item. O ID do item deve ser separado por vírgulas e o número de itens deve ser de no máximo 50. |
